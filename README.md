# Coreclock
Windows desktop employee attendance and time tracking system built with C# WinForms.

## Prerequisites
- Windows OS
- .NET 10 SDK (https://dotnet.microsoft.com/)

## How to Run
1. Clone the repo
2. Open `Coreclock.slnx` in Visual Studio or run `dotnet run` in the `Coreclock` directory
3. Build and launch the app

## Features
- Employee login/registration
- Clock in/out with attendance logs
- Admin/employee dashboards
- Shift and schedule management
- Attendance reports
